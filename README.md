# @obitrain/react-native-image

Nitro image view for obiapp: Kingfisher on iOS, Coil 3 on Android, decode-to-size

## Installation


```sh
npm install @obitrain/react-native-image react-native-nitro-modules

> `react-native-nitro-modules` is required as this library relies on [Nitro Modules](https://nitro.margelo.com/).
```


## Usage


```js
import { ReactNativeImageView } from "@obitrain/react-native-image";

// ...

<ReactNativeImageView color="tomato" />
```
